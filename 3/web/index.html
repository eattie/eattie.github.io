1.1 Finite Difference Operator

1.2 Edge Detection

I applied finite difference operators Dx and Dy to the cameraman image to compute partial derivatives. I calculated the gradient magnitude using sqrt(Dx² + Dy²) and binarized the result using a threshold of 0.175 to create edge images.

I tried several threshold values but settled on 0.175 as it gave the best balance between capturing important edges and suppressing noise. Lower values included too much noise, while higher values missed edge details I wanted to preserve.

1.3 Derivative of Gaussian (DoG) Filter

I created a Gaussian filter using cv2.getGaussianKernel(10, 3) and applied it before computing derivatives to reduce noise. I also created Derivative of Gaussian filters by convolving the Gaussian with Dx and Dy.

Part 2: Fun with Frequencies

2.1 Image "Sharpening"

I implemented unsharp masking to sharpen images by extracting and amplifying high frequencies. I used the formula: sharpened = image + α(image - blurred_image), - where α = 2 controls the sharpening strength. I applied this to both the Taj Mahal and banana tree images.

2.2 Hybrid Images

I created hybrid images by combining low frequencies from one image with high frequencies from another. Using the aligned Derek and Nutmeg images, I applied a low-pass filter (σ=10) to Derek and a high-pass filter (σ=3) to Nutmeg, then combined them. 2.3 Gaussian and Laplacian Stacks

I created Gaussian stacks by repeatedly applying a Gaussian filter (σ=4) to progressively blur the images across 6 levels. For the Laplacian stacks, I subtracted adjacent Gaussian levels to isolate specific frequency bands, with the final level containing the lowest frequencies from the last Gaussian level. I applied scaling factors for better visualization of the different frequency bands.
