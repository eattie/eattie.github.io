A.4: Blend the Images into a Mosaic

For this part I blend warped images using weighted averaging with alpha masks. Each image gets a weight mask with linear falloff from center to edges. In overlapping regions, pixels are combined as (im1×α1 + im2×α2) / (α1 + α2), to make a smooth blend. Initialy, I used a weighted average of 1/2 for the overlapping region, but there was a sharp line and it just didn't look good at all. Also I'm pretty sure I messed up my point selection because it's a little bit blurry but I just found it so hard to get accurate selections

B.3: Feature Matching

I matched features between images using Lowe's ratio test. For each descriptor, I found its two closest matches and only kept it if the best match was significantly better than the second-best (ratio < 0.75).

B.4: RANSAC

I estimate homographies with 4-point RANSAC: repeatedly sample 4 correspondences, compute H, count inliers within a threshold distance, then recompute H using all inliers. After many iterations, I use the best H to warp and blend images into automatic panoramas. This is a funny observation but I realized I suck at point selection (my part A mosaics were a bit blurry)
